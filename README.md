# PlainSense
AT app that explains error messages, popups, and overall computer basics. Aimed at helping senior citizens and those with limited digital literacy, on how to use their computer calmly and confidently. Language and UI/UX is kept plain in order to be simple and trustable for a demographic that would find a modern layout overwhelming.
Camera/OCR feature was not implemented. LLM may have run out of tokens or has been deactivated.
